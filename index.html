Objectif du projet

Pourquoi ce quiz existe et ce qu'il apporte à l'apprentissage de JavaScript.

Problématique

L'apprentissage de JavaScript souffre d'un manque d'outils interactifs adaptés au contexte universitaire marocain. Les étudiants ont besoin d'une plateforme qui évalue leurs connaissances de manière progressive et ludique.

Solution proposée

JSQuiz propose des exercices variés — QCM, association, complétion et débogage de code — organisés par niveaux. Chaque réponse est suivie d'une explication pour consolider l'apprentissage.

Public cible

Étudiants de la filière Informatique et Intelligence Artificielle, du débutant à l'avancé. Le système de niveaux s'adapte à chaque profil pour une progression efficace.

Compétences visées

  • Niveau 1 : Introduction à JavaScript
  • Niveau 2 : Fondamentaux de JavaScript
  • Niveau 3 : Les Fonctions
  • Niveau 4 : Objets & Tableaux
  • Niveau 5 : DOM en JavaScript
  • Niveau 6 : Événements, POO, jQuery & AJAX

À propos du jeu

Tout ce qu'il faut savoir sur le fonctionnement technique.

Niveaux de difficulté

6 niveaux répartis en 3 paliers progressifs :

  • Débutant (Niveaux 1 & 2)
  • Intermédiaire (Niveaux 3 & 4)
  • Difficile (Niveaux 5 & 6)

Types d'exercices

  • QCM classique
  • Association d'éléments
  • Complétion de code
  • Débogage de code

Technologies utilisées

  • HTML5 sémantique
  • CSS3 : variables, Grid, animations
  • JavaScript vanilla (ES6+)

Système de scoring

  • Points par difficulté
  • Bonus de temps
  • Historique sauvegardé
  • Classement visible
